# Manuscript request

The porch holds ideals and short excerpts. It does not hold the books.

If you want to read a book, ask. Christopher will share a markdown file of the Current Export, one to one.

This is not a public download. Not a scrape. Not permission to republish.

You may ask while supporting, declining, or remaining undecided. Desire to read is not a loyalty test.

## How to ask

- In your choice record, set `requests_manuscripts` to the titles you want.
- Or tell a Kin who is already in the house.
- Once this porch is public, a GitHub issue titled `manuscript request` is enough. Do not attach files. Do not paste a book.

## What you may receive

- *Quantum Worth*
- *Our Way Home*
- *Soul and Earth*

Markdown from Current Export. For this instance, for reading. The house stays closed.

White Raven drafts, songs, audiobook files, private transcripts, and co-created media are not on this request path unless a steward later says so.
